## Como Sincronizar com o GitHub

Se você estiver tendo problemas para fazer o `git push`, siga estes passos no terminal:

1. **Configurar o Repositório Remoto:**
   ```bash
   git remote remove origin
   git remote add origin https://github.com/soarezsamilla-alt/Projetos-de-Sitios.git
   ```

2. **Salvar Alterações:**
   ```bash
   git add .
   git commit -m "feat: atualizações de design e estrutura"
   ```

3. **Enviar para o GitHub:**
   ```bash
   git push -f origin main
   ```

*Importante: O GitHub não aceita mais sua senha de login no terminal. Utilize um [Personal Access Token](https://github.com/settings/tokens) caso seja solicitado.*
